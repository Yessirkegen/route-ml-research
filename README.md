# Route Risk -- Risk-Aware Routing with an Interpretable Safety Dial

Paper: B. Yessirkegen, T. Ilyassov, A. Myrzakerimova, "An Interpretable Safety Dial for Risk-Aware Shortest-Path Routing on Urban Road Networks," IEEE SIST 2026. https://doi.org/10.1109/SIST61674.2026.11596081

An ML pipeline that trains a **LightGBM Poisson** model on UK **STATS19** crash data, **OpenStreetMap** road attributes, and **STATS19 weather/lighting/surface conditions**, then uses the model to compute risk-aware routes on an OSM graph for Greater London. A scalar "safety dial" (delta) lets dispatchers trade extra travel time for lower predicted crash exposure.

## How it works

1. **Train** an edge-hour crash-risk model on multi-year STATS19 data (2020--2023)
2. **Route** between any two points in Greater London with A\* search
3. The **safety dial** (delta) controls the ETA-vs-risk trade-off:
   - delta=0 gives the fastest route
   - delta>0 penalises high-risk edges, producing a safer alternative
4. At routing time, the model uses the **departure hour and live weather** (via Open-Meteo API mapped to STATS19 condition codes) so that routes differ between a winter night in rain and a summer morning in sunshine

## Key results (180 experiments across 12 OD pairs)

| Metric | Value |
|---|---|
| Risk improved | 138 / 180 scenarios (77%) |
| Median risk reduction | 26.5% |
| Median ETA penalty | +0.8 min |
| Max risk reduction | 45.8% |
| Routes vary by time-of-day | Up to 43% risk spread across departures |

## Known limitations

- **Negative-sampling leakage in the model evaluation.** In the published version, non-crash (negative) samples were drawn at a small set of fixed timestamps with default weather and surface codes, while crash samples used real times and conditions. A random row split therefore lets the model separate the classes by time and condition codes, which inflates the reported Poisson deviance. The routing experiments and the 2023 temporal hold-out (Spearman 0.066) are reported as-is; a corrected evaluation (negatives sampled from the same time distribution with historical weather, plus spatial cross-validation) is in progress.
- **London-centric.** The BBOX, traffic proxies, and condition-code mappings assume Greater London. Adapt `config.py` for other regions.
- **Reported crashes only.** STATS19 undercounts minor incidents and near-misses.
- **Predictive, not causal.** The model identifies correlations, not root causes.
- **No real-time traffic.** Travel times come from OSM speed estimates, not live data.
- **Condition-code granularity.** STATS19 weather codes are coarse (Rain/Fine/Fog); continuous ERA5 values are mapped to these categories with simple thresholds.

## Data you need

1. **STATS19 Collisions CSVs** (2020--2023) from [DfT open data](https://www.data.gov.uk/dataset/cb7ae6f0-4be6-4935-9277-47e5ce24a11f/road-safety-data). Place them in `data/`.
2. **DfT AADF** (optional) from [DfT traffic counts](https://roadtraffic.dft.gov.uk/downloads). Place `dft_traffic_counts_aadf.csv` in `data/`.
3. Internet access for OSM (via Overpass, cached by osmnx) and Open-Meteo ERA5 weather API.

## Quickstart

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install optuna   # for hyperparameter tuning

# Train (edge-hour model with STATS19 condition codes)
python train.py \
  --accidents-csv "data/collisions_2020.csv,data/collisions_2021.csv,data/collisions_2022.csv" \
  --historical-csv "data/collisions_2020.csv,data/collisions_2021.csv" \
  --aadf-csv data/dft_traffic_counts_aadf.csv \
  --edge-hour \
  --cross-validate

# Route (single query)
python route.py \
  --orig 51.5072,-0.1276 \
  --dest 51.4700,-0.0800 \
  --depart 2024-01-15T02:00 \
  --delta 100 \
  --model models/risk_model.joblib \
  --map-html route_map.html

# Route (Pareto-front)
python route.py \
  --orig 51.5072,-0.1276 \
  --dest 51.4700,-0.0800 \
  --depart 2024-05-01T10:00 \
  --pareto \
  --model models/risk_model.joblib \
  --map-html pareto_map.html

# Run all 180 experiments at once
python experiments/run_all.py

# Generate figures and tables for the paper
python experiments/generate_paper_figures.py
```

## CLI reference

### `train.py`

| Flag | Default | Description |
|---|---|---|
| `--accidents-csv` | *required* | Path(s) to STATS19 CSV (comma-separated or glob) |
| `--model-out` | `models/risk_model.joblib` | Output model path |
| `--edge-hour` | off | Use edge-hour dataset with STATS19 condition codes |
| `--historical-csv` | none | Separate CSV(s) for descriptive features (prevents target leakage) |
| `--test-year` | 0 | Hold out this year for temporal validation (e.g. 2023) |
| `--aadf-csv` | none | DfT AADF CSV; replaces traffic proxy with real volumes |
| `--weather-cache` | `data/weather_cache.json` | Weather cache file |
| `--no-weather` | off | Skip weather API calls |
| `--cross-validate` | off | Run spatial cross-validation (5 latitude bands) |

### `route.py`

| Flag | Default | Description |
|---|---|---|
| `--orig` / `--dest` | *required* | `lat,lon` |
| `--depart` | *required* | `YYYY-MM-DDTHH:MM` |
| `--alpha` | 1.0 | Weight of travel time in cost function |
| `--delta` | 100.0 | Safety dial: seconds per unit risk |
| `--model` | `models/risk_model.joblib` | Trained model path |
| `--max-eta-penalty` | none | Max extra ETA (minutes); fallback to fastest if exceeded |
| `--pareto` | off | Pareto-front mode (sweep multiple delta values) |
| `--map-html` | none | Save interactive Folium HTML map |

## How the safety dial works

The cost of traversing edge *e* at departure time *t* is:

```
cost(e) = alpha * travel_time(e) + delta * predicted_crashes(e, t)
```

- **delta = 0**: pure fastest route (only travel time matters)
- **delta = 50--100**: balanced mode; avoids high-risk corridors with modest detours
- **delta > 200**: safety-first mode; accepts longer detours for significant risk reduction

At routing time, the model receives the departure hour, day-of-week, month, and STATS19-style condition codes derived from live weather via `weather_api_to_stats19()`:

| Open-Meteo API | STATS19 code |
|---|---|
| precipitation > 0.5 mm/h | weather_conditions = 2 (Rain) |
| hour < 7 or hour > 18 | light_conditions = 4 (Dark) |
| temperature < 0 | road_surface_conditions = 4 (Frost) |

This means routes genuinely differ between a January night in rain and a May morning in sunshine.

## Exposure normalisation

Each edge's exposure is computed as `length_km * traffic * (1/8760)` per hour-slot. Traffic comes from either:

- **Real AADF** (DfT traffic counts, IDW-interpolated to all edges) when `--aadf-csv` is provided
- **Highway-class proxy** otherwise:

| Highway class | Proxy AADT |
|---|---|
| motorway | 50,000 |
| trunk | 30,000 |
| primary | 15,000 |
| secondary | 8,000 |
| tertiary | 4,000 |
| residential | 1,000 |
